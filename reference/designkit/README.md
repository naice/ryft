# RYFT — Brand & Coding Agent Starter Kit

Contains editable vector app icon and raster sizes, design system, architecture spec and a ready-to-use coding agent prompt. This is a **design and specification kit**, not a finished Electron application.

1. Copy contents into your repository.
2. Give your coding agent `agent/CODING_AGENT_PROMPT.md` and point it to this folder.
3. Build in phases; review security and SSH host-key handling before release.

The RYFT name has not been legally cleared for commercial use. Check trademark and existing software usage.
