# Sicherheit

Unterstützt wird nur das jeweils neueste Release.

Bitte melde Schwachstellen direkt an den Inhaber des Repositories, nicht als öffentliches Issue. Füge keine echten Passwörter, Schlüssel oder Hostnamen an.

Das Sicherheitsmodell ist in der [README](README.md#sicherheitsmodell) beschrieben.
